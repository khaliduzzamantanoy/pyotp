Documentation

API Endpoints:

GET/POST /api/sendsms - Send SMS

  • Method: GET or POST
  • Authentication: api_key as query parameter OR X-API-Key header
  • Parameters: Query params (GET) or JSON body (POST)
  • Required: api_key, msg, to
  • Optional: schedule, sender_id, content_id

GET /api/report/request/<id>/ - Check SMS delivery status

  • Method: GET
  • Authentication: api_key as query parameter
  • Parameters: Query parameters only
  • Required: api_key (query), id (URL path)

GET /api/user/balance/ - Check SMS balance

  • Method: GET
  • Authentication: api_key as query parameter
  • Parameters: Query parameters only
  • Required: api_key

POST /api/verify_otp - Verify OTP

  • Method: POST
  • Authentication: X-API-Key header
  • Content-Type: application/json
  • Body: JSON with phone_number and otp_code

GET /get_pending_otp_send - Get pending OTP for device (MicroPython)

  • Method: GET
  • Authentication: None required
  • Parameters: None

Parameters:

  • api_key - Your API key (query parameter or header)
  • msg - Message content (OTP should be included in the message from client server)
  • to - Recipient number(s), comma-separated for multiple
  • schedule - Optional schedule time (Y-m-d H:i:s format, e.g., 2025-11-13 22:54:50)
  • sender_id - Optional approved Sender ID
  • content_id - Optional approved campaign content ID

Request Examples:

1. Send SMS (GET - Query Parameters):

GET /api/sendsms?api_key=YOUR_KEY&msg=Your%20OTP%20is%20123456&to=8801800000000

2. Send SMS (POST - JSON Body):

POST /api/sendsms?api_key=YOUR_KEY Content-Type: application/json { "msg": "Your OTP is 123456", "to": "8801800000000" }

3. Check Report (GET):

GET /api/report/request/1/?api_key=YOUR_KEY

4. Check Balance (GET):

GET /api/user/balance/?api_key=YOUR_KEY

5. Verify OTP (POST - JSON Body):

POST /api/verify_otp X-API-Key: YOUR_API_KEY Content-Type: application/json { "phone_number": "8801800000000", "otp_code": "123456" }
